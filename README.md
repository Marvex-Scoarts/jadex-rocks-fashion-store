# JADEX ROCKS

**Elegance Carved in Stone** — A luxury fashion e-commerce storefront built from scratch with HTML, CSS, and JavaScript.

## About the Project
Jadex Rocks is a collaborative web design project created for fun, blending high-contrast editorial luxury with a clean, gallery-inspired shopping experience.

## Design & Aesthetic
* **Hybrid Color Palette:** Combines crisp minimalist alabaster white and brushed silver product cards with dramatic onyx black banners and champagne gold accents.
* **Editorial Typography:** Pairs *Cormorant Garamond* serif headings with clean *Montserrat* body text.

## Features
* **Sticky Luxury Navigation:** Quick access to collections, brand story, and a live shopping bag counter.
* **Responsive Product Grid:** Hover-zoom product cards featuring bespoke Jadex Rocks pieces.
* **Interactive Slide-Out Bag:** Add items, remove items, and view automatic dollar subtotals in real time.

## Built With
* **HTML5** — Semantic storefront structure
* **CSS3** — Custom variables, Flexbox, CSS Grid, and smooth hover transitions
* **Vanilla JavaScript** — Dynamic shopping bag state and interactive drawer controls
